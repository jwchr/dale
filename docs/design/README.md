# Dale design reference

Jeff supplied these pictures on November 19, 2026 for issue #101 (the new "Household" look).
They are design concepts. Every number, time, bus, gate, "LIVE" mark and "Household Beta" pill in them is sample content, not real data, and must never be copied into the app as if it were real.

These pictures control visual acceptance for #101: each part of #101 is compared against them on a real phone-sized screen before it counts as done.
The plan for the parts is in the #101 comment of November 19, 2026.
